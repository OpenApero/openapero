# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes       |

## Reporting a Vulnerability

Please do not open a public issue for a security problem. Report it privately by
email to the maintainer listed in the `package.xml` files, Kaixian Qu
(<kaixqu@ethz.ch>), and include the affected version, what you observed, and the
steps to reproduce it.

You will get an acknowledgment within a reasonable time, and an update once the
report has been assessed. There is no bounty program.
